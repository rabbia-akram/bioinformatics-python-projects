# Bioinformatics Python Projects

Three beginner projects made with Python. I have an MSc in Zoology and I am moving into bioinformatics.

## Project 1: DNA Sequence Analyzer
Reads the human insulin gene (NM_000207,from NCBI) and finds:

- Count of A, T, G, C
- GC content (63.87 percent)
- Reverse complement

File: DNA project/dna analyzer.py

## Project 2: Lipinski Rule Checker
Checks if a drug can work as an oral medicine, using Lipinski's rule of five (molecular weight, logP, hydrogen bond donor and acceptors). Tested on 5 drugs. Values checked on PubChem.

File: Drug project/Lipinski checker.py

## Project 3: Protein Analyzer
Reads the human insulin protein (NP_000198, from NCBI) and finds: 

- Protein length (110 amino acids)
- Percent of hydrophobic amino acids (46.36 percent), using a simple list of hydrophobic amino acids
- Most common amino acid

File: Protein project/protein analyzer.py
